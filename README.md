# ZimaOS Apps
A collection of applications designed to run on ZimaOS. Each app can be installed, managed, and accessed through the ZimaOS App Store. These have been tested and configured with the ZimaBoard 2 and an external GPU.

## App List
- [Cooler Control](cooler-control/README.md): Manage your CPU and GPU temperatures and performance.
- [ZimaDjango](django/README.md): Run a local Django development server.
- [MetaTrader5](metatrader5/README.md): Run MetaTrader 5 in your browser.
