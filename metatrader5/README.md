# MetaTrader5
Run MetaTrader5 using Docker. Its accessible in your browser at http://localhost:3000 after installation.

The Docker image is from: https://github.com/gmag11/MetaTrader5-Docker/pkgs/container/metatrader5-docker

## Installation
1. Open up your ZimaOS Dashboard.
2. Open up the `App Store`
3. Click on `My Apps`.
4. Click on `Install Custom App`.
5. Click on `YAML`.
6. Replace the contents with the `metatrader5.yaml` file.
7. Update your `source` to match your external drive. By default it will save in `ZimaOS-HD/AppData/mt5`
