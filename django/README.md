# ZimaDjango
Run a local Django development server using Docker. Its accessible in your browser at http://localhost:8000 after installation.

## Installation
1. Open up your ZimaOS Dashboard.
2. Open up the `App Store`
3. Click on `My Apps`.
4. Click on `Install Custom App`.
5. Click on `YAML`.
6. Replace the contents with the `django.yaml` file.
7. Update your `source` to match your external drive. By default it will save in `ZimaOS-HD/AppData/zimadjango`

## Usage
Each ZimaOS app has a `Terminal` where you can run commands related to the app. For ZimaDjango, you can use the terminal to manage your Django project, run migrations, and edit configuration files as needed.

Hover over the `ZimaDjango` app in your dashboard, click the `...`, and select `Terminal` to open the terminal for managing your Django project.
